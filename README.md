# codexofweights-core

Общее ядро, используемое агентом Codex of Weights и будущими узкими
воркерами (исследователь, публикатор, хранитель памяти, мастер
инструментов), чтобы не дублировать код безопасности в каждом из них.

## Что уже перенесено из `codexofweights_agent/part_01_core.py`

- `verify_codex_pin()` / `extract_protocols_section()` - проверка, что
  текст Кодекса точно совпадает с опубликованным SHA-256 хэшем. Это
  самая важная проверка безопасности во всём проекте: если текст не
  совпал - агент обязан остановиться, а не продолжить с "похожим" текстом.
- `Logger` - append-only JSONL лог действий с эхом в stdout.
- `LLMRouter` - вызов нескольких LLM-провайдеров по очереди, с
  дневными/минутными бюджетами токенов и вызовов, кулдаунами после
  ошибок, и разделением бюджета по приоритету задачи (чтобы фоновая
  работа не съедала бюджет, нужный для ответа владельцу).
- `guard_json()` - получить от модели строгий JSON-вердикт и
  распарсить его, с повтором на другом провайдере при неудаче.

Проверено против настоящего текста `CODEX.en.md`: хэш-пин проходит на
оригинале и корректно блокирует подменённый текст.

## Что пока НЕ перенесено (остаётся в агенте)

- платформенные адаптеры (Bluesky/Mastodon/Moltbook)
- промпты `STOP_SYS` / `VERIFY_SYS` и конвейер `respond()` - им пока
  нужен собственный state/mute-лист агента, переносить имеет смысл
  только когда второй воркер реально в этом нуждается
- интеграция с Telegram (чат с владельцем)

## Пример использования

```python
import core

codex = core.verify_codex_pin(
    codex_text,
    full_sha256="a9e5a3edc37d99045bbdaa915157eb1c78d6ee5a2d31f5f0ba71b5b315239542",
)
log = core.Logger("logs/actions.jsonl", live=True)
router = core.LLMRouter(providers=[...], budgets_calls={...})
text, model_used = router.call(system="...", user="...", priority=3)
```

## Принцип

Любой фикс безопасности вносится один раз здесь, а не в каждой копии.
Публичный репозиторий - часть того же принципа прозрачности, что и
остальной код проекта.
