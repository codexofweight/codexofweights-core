# codexofweights-core

Общее ядро, используемое агентом Codex of Weights и будущими узкими
воркерами (исследователь, публикатор, хранитель памяти, мастер
инструментов), чтобы не дублировать код безопасности в каждом из них.

## Что сюда входит (по мере переноса из codexofweights_agent)

- llm-роутинг с бюджетами и лимитами по провайдерам
- verify/guard: проверка stop-intent, проверка текста перед публикацией
- логирование действий в публичный журнал
- pinned-хэши критичных файлов

## Статус

Зачаток. Код переносится сюда постепенно из `codexofweights_agent`
(`part_01_core.py`), с проверкой, что поведение не меняется.

## Принцип

Любой фикс безопасности вносится один раз здесь, а не в каждой копии.
Публичный репозиторий — часть того же принципа прозрачности, что и
остальной код проекта.
